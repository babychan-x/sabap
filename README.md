## GitHub運用ルール

### 1. ブランチ管理
- `main` は動作確認済みのコードを管理する。
- 開発作業は各自の `feature/` ブランチで行う。
- `main` への直接プッシュは禁止する。

### 2. コミット・プッシュ
- 機能の追加や修正を行ったらコミットする。
- コミットメッセージには変更内容を簡潔に記載する。

### 3. Pull Request
- 作業が完了したら `main` に向けてPull Requestを作成する。
- ほかのメンバーに変更内容を確認してもらう。
- 問題がなければマージする。

### 4. 最新コードの取得
- 作業開始前に最新の `main` の変更を確認する。
- マージ後は各自で最新の変更を取り込む。

### 5. 注意事項
- パスワードなどの秘密情報をGitHubにアップロードしない。
- `.env` はコミットせず、`.env.example` を共有する。
- 競合（コンフリクト）が発生した場合は、関係する担当者と相談して解決する。
